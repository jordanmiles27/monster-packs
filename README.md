# MonsterDialer Community Packs

This repository publishes a MonsterDialer pack catalog.

The catalog is available at:

`https://jordanmiles27.github.io/monster-packs/catalog.json`

Pack archives will be added under `packs/` and listed in `catalog.json` with their
exact byte size and SHA-256 digest. See the [catalog format guide](https://github.com/oxcened/monster-dialer/blob/main/docs/catalogs.md)
before publishing a pack.
